# Phase 2 — Backlog

Decisions and features deferred out of MVP scope, to be revisited later.

## External recipe source integration

MVP does not use an external recipe API (Spoonacular, Edamam, etc.) — the Claude API is sufficient for both recipe generation and nutrition estimation, and these APIs' free tiers are unclear/limited, which conflicts with the zero-budget MVP goal.

To evaluate in Phase 2:
- Spoonacular API (recipe + nutrition data)
- Edamam Recipe API
- Goal: add a broad external recipe pool alongside our own/AI-generated recipes (to enrich search/discovery)
